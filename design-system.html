Animation Classes
Drop-in animation classes. Add with JS IntersectionObserver for scroll-triggered reveals.
↑
.anim-fade-up
○
.anim-fade-in
→
.anim-slide-right
⊕
.anim-scale-in
/* Scroll-triggered via JS */
const observer = new IntersectionObserver(entries => {
  entries.forEach(e => { if (e.isIntersecting) e.target.classList.add('anim-fade-up'); });
});
document.querySelectorAll('.hidden').forEach(el => observer.observe(el));
Glow Effects
Floating blurred radial gradients for ambient depth. Always position: fixed / absolute with pointer-events: none.

This card has a .glow-bg class — two blurred pseudo-elements create teal + gold ambient light. Great for hero sections, CTAs, and feature cards.

.glow-bg::before {
  content: ''; position: absolute;
  width: 200px; height: 200px;
  background: rgba(43, 163, 182, 0.12);
  border-radius: 50%; filter: blur(80px);
  animation: float 8s infinite alternate ease-in-out;
  pointer-events: none;
}
